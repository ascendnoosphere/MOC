1. A REAL-PART LEMMA WITH NO REAL-LIFT ASSUMPTION.

Let F be a homogeneous cubic with real coefficients and let z=c+id,
c,d real, satisfy grad F(z)=0. Write H_F for its Hessian. Expanding the
quadratic gradient gives
  grad F(c)=grad F(d),   H_F(c)d=0.
Symmetry of the cubic tensor gives
  3F(c)=c dot grad F(c)
       =c dot grad F(d)
       =(1/2)d^T H_F(c)d=0.
Therefore F(Re z)=0. Also H_F(c) is singular: if d is nonzero it is a
kernel vector; if d=0, Euler's differentiated identity
H_F(c)c=2 grad F(c)=0 supplies a kernel unless c=0, when H_F(c)=0.

Apply this to the verified eight-spinor skew cubic F, whose singular
locus contains every actual complex four-site spectral product vector.
Complex scaling preserves this property. Let e be the constant profile.
The same verified model has
  F(x+t e)=F(x)+t Q(x),   Q(x+t e)=Q(x),
where Q is its quadratic singlet determinant and H_e=H_F(e).

An actual real support deficit is g=h e-Re(eta z). Set
c=-Re(eta z)=g-h e. The preceding lemma gives
  F(g)-h Q(g)=F(c)=0.
Thus Q(g)=0 implies F(g)=0. This directly proves the exceptional-case
implication used below; it does not assume that an arbitrary real vector
has a compatible imaginary lift.

If Q(g) is nonzero, necessarily h=F(g)/Q(g), and singularity of H_F(c)
implies
  det(Q(g)H_F(g)-F(g)H_e)=0.
These are necessary actual-spectral conditions; no converse is asserted.

real-part lemma excludes an actual spectral deficit because F(g) is

again excluding an actual spectral deficit. Consequently every actual
spectral deficit in this face has c=0. On that boundary it is a
nonnegative combination of two ordinary squared-minor indicators, so
its evaluation at every unitary is nonnegative. This completely closes
this particular mixed-face family, including its Q=0 branch.
