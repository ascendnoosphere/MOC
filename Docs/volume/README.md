# Volume dependency notes

[The algebraic input needed by the positivity proofs](standalone_dependency_note.md) separates elementary necessary spectral equations from the stronger invariant-theory identification used in the collected proof record.

## Contents

- Sections 1–3 fix the fourteen matching coordinates, the cubic, polarization identities, and the degree-eighteen necessary equation.
- Section 4 explains how the tetrahedral positivity argument uses that necessary equation.
- Sections 5–6 state the Howard–Millson–Snowden–Vakil input and identify where stronger structural results and other standard inputs enter.
- Section 7 gives an elementary proof of the classical Hermitian determinant comparison, including singular extrema.

The chapter uses the volume's appendix names and equation labels. Related standalone sources are indexed under [finite and spin geometry](../theorems/finite_and_spin_geometry/README.md) and [support certificates](../theorems/support_certificates/README.md). [Volume code](../../code/volume/) contains TeX postprocessing utilities, not an independent verification of the chapter's mathematical claims.
