# Support certificates and sharp bounds

These notes prove support inequalities under specified symmetry, spectral, or geometric hypotheses. Other notes separate finite certificate cones from larger positive classes or identify the universal inequality still needed. Use each theorem's stated scope; one support direction and all directions for a spectral pair are different conclusions.
