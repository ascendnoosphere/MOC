Two five-budget families closed by nonlinear prior capacities
============================================================

Scope and inputs
----------------
For each of the two ID lists below, every cost

    g=t*r34 + sum_j nu_j*r_j,    t,nu_j >= 0,

with det M(g)=0 has a full matching SOS. This is a statement about these
two entire families, including zero budgets. It does not assert that all
formal N9 costs are SOS, and does not use source realizability. Consequently
it applies to actual spectral support costs, whose inverse pencil has rank
at most8. At t=0 every summand is an ordinary Boolean square. For t>0,
divide all budgets and the cost by t, prove the normalized assertion, and
multiply the resulting Gram by t.

The exact verifier freshly expands both full9x9 integer determinants,
with a checked int128 coefficient bound, and compares every coefficient
with the factor census. All factors other than the displayed R have
nonnegative coefficients and a positive constant. Therefore N9=0 is
equivalent to R=0 on the nonnegative budget orthant.

Family A: IDs [13,17,18,27,30]
--------------------------------
Write the budgets (a,b,c,d,e) in that order. The contacts are
(1,6,7,8,9,14,17,20). Its mixed determinant factor is

    R=R0-d*T,
    R0=(a+1)(c+1)(e+1)(a+b+1)>0.

Set

    p=ac-1, H=(e+1)(a+1),
    K=H*c(c+1)+b*((e+1)(a-c)^2+(a+1)(c+1)).

The exact identity T=pH-K has H>0,K>=0. At R=0 we have dT=R0>0,
so d,T>0, and then p>0. Moreover

    T*(dp-a)=p*R0-a*T=p*(R0-aH)+aK >= 0,
    R0-aH=(a+1)(e+1)(ac+bc+b+c+1)>0.

It follows that

    acd-a-d >= 0.

This is the previously proved D1 core on [13,18,27], with positive
a,c,d: p>0 gives a,c>0, while d>0 was forced above. Its full4-feature
Gram is PSD. Add the unused b*r17 and e*r30 Boolean squares.

Family B: IDs [7,13,20,27,31]
--------------------------------
Write the budgets (a,b,c,d,e) in that order. The contacts are
(1,6,8,9,12,14,18,23). Its mixed determinant factor is

    R=R0-e*T,
    S=(a+1)(b+1), R0=S*(a+c+1)*(b+d+1)>0.

Set

    p=ab-1, H=S+bc+ad,
    K=c*(a^2*b+a^2+a+1)+d*(a*b^2+b^2+b+1)+cd*(a-b)^2.

Again T=pH-K exactly, with H>0,K>=0. A root forces e,T>0 and p>0.
The second exact identity is

    T*(pe-ab-a-b-1)
      =p*R0-(ab+a+b+1)*T
      =S*[S*(ac+bd)+cd*((a-b)^2+p)] >= 0.

Hence the D2 capacity

    abe-ab-a-b-e-1 >= 0

holds. In feature order (r13,r7,r31,r34), the representing Gram is

    [ b -1  1  0 ]
    [-1  a  1  0 ]
    [ 1  1  e -1 ]
    [ 0  0 -1  1 ].

The D2 square decomposition already proves it PSD. The verifier also
checks all24 cost values for this transformed core directly. Add the
unused c*r20 and d*r27 Boolean squares.

Why the previous coefficient LP missed these implications
---------------------------------------------------------
The useful prior capacity p is not a nonnegative-coefficient polynomial
in the original budgets. Its positivity follows first from R=0 and the
identity T=pH-K. Only after that step do the displayed square-containing
expressions certify the target D1/D2 capacities. This is a whole-parameter
proof, not a list of positive evaluations.
