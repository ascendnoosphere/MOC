EXACT CLOSURE OF THE TWO-MIXED-RAY NINE-CONTACT FACE

This proves the support inequality on the coefficient face generated by
(3,19,22,29,52,74), including its boundary. It does not prove MOC4 globally.
The code code/research/verify_two_mixed_face_52_74.py checks the polynomial identities using the
certified exact cubic, and tests the ray identity at all permutations.

Write
  g = a r3 + b r19 + c r22 + d r29 + t f52 + s f74,
with all coefficients nonnegative. If t=s=0, g is already an ordinary
nonnegative minor sum. Otherwise define
  Q = bc+bd+bt+bs+cd+ct+cs+dt+ds+t^2+ts+s^2 > 0.
The exact cubic model yields
  F(g)=(a+t+s)Q,  D_e F(g)=Q.
For any actual spectral gap, F(g)=h D_e F(g), hence h=a+t+s>0.
With x=g-he, the spectral lift y obeys H_x y=0 and grad F(y)=grad F(x).
The nonzero vector x is certified by its first selected coordinate
x_0=-(a+t+s). Thus H_x is singular: if y is nonzero this is immediate;
if y=0, then grad F(x)=0 and H_x x=2 grad F(x)=0.

The exact determinant identity is
  det H_x = -4(t-s)^4 (a+t+s)^6 Q^2.
All other factors are strictly positive, so t=s. The verifier computes this
identity with s=1; homogeneity and polynomial continuation give it for all s,
including s=0. In particular an actual gap cannot have exactly one positive
mixed coefficient.

Finally, exact permutation coordinates give
  f52+f74 = 2 r3+r19+r22+r29.
This equality holds on every unitary: each squared-minor profile is a linear
combination of permutation coordinates, by complementary minors and the
Leibniz expansion (see docs/geometry/profile_safe_cone_audit.txt). Hence
  g=(a+2t)r3+(b+t)r19+(c+t)r22+(d+t)r29 >= 0
for every complex unitary U(4). This conclusion includes degenerate spectra
and does not require distinct products. The census lists 96 faces in this orbit.
