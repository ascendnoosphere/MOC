No fixed linear Gram formula for all actual supporting gaps
31 October 2026

There is no fixed linear map taking every actual MOC4 supporting gap g
to a positive-semidefinite reduced auxiliary Gram matrix C(g) with those
costs. The same holds for affine maps. This obstruction applies before
the exceptional partial-transpose condition is imposed. It does not
refute universal feasibility of the auxiliary cone: a certificate may
depend nonlinearly on the gap or on its spectral parameters.

Use the physical reduced coordinates from
 moc_exact_ppt_jet_certificate.py:
 T=W C W*, psi=J conjugate(W),
 g_pi=conjugate(psi_pi) C psi_pi^T.
The matrix W has full column rank14 and C>=0 is equivalent to T>=0.

For each i,j let r_ij(pi)=1_{pi(i)=j}. This is an actual supporting gap,
including its degeneracies, rather than an arbitrary nonnegative cost.
Indeed choose a_i=0, all other a=1; b_j=1, all other b=0. Then
 product_k(a_k+b_pi(k))=r_ij(pi).
The supporting direction eta=-1 has support value0, so its gap equals
r_ij exactly. Thus any theorem covering unrestricted spectra must include
all sixteen of these costs.

The exact ordinary-ray witnesses in
 data/certificates/moc_ppt_ordinary_rankone_witnesses.json
give a vector v_ij with psi conjugate(v_ij)=r_ij. The associated matrix
v_ij v_ij* is a PSD certificate. More strongly, it is the only PSD
certificate supported on W. To see this, a PSD matrix realizing r_ij
must annihilate every feature vector psi_pi^T for which r_ij(pi)=0.
Those eighteen zero-cost feature vectors have rank13, verified exactly
over QQ(i). Their orthogonal complement is one-dimensional and contains
v_ij. Thus C=lambda v_ij v_ij*; evaluating a permutation with r_ij=1
forces lambda=1.

Now the four cost partitions satisfy
 sum_j r_0j = sum_j r_1j = 1.
A linear section would therefore require
 sum_j v_0j v_0j* = sum_j v_1j v_1j*.
They are not equal. In the exact Gaussian-integer W basis used above,
the difference of their (0,0) entries is -2/27. This is a contradiction.
For an affine section, each four-term sum has the same additional four
copies of the affine offset, so the same contradiction applies.

The verifier
 python code/research/moc_no_linear_ppt_section.py
checks all sixteen actual product realizations, the sixteen rank13
zero-feature statements, all indicator evaluations, and the nonzero
partition difference using only exact rational complex arithmetic. Its
report is build/moc_auxiliary_ppt_jet/no_linear_section_exact.json.

This gives a concrete restriction on the desired global identity. A
single fixed linear right inverse of the cost-evaluation map cannot work
even on the elementary actual indicator gaps. A successful universal
construction must adapt its Gram choice, or use a different mechanism.
