Eight-contact cap [0,7,10,18,22,34]: closure of equal ordinary weights

Let
 g=a r0+a r7+c r10+d r18+e r22+r34,  a,c,d,e>=0,
and let F be the exact 14-coordinate cubic, E the all-ones vector, and
Q=D_E F. The two portable exact verifiers below rely on the model verifier.
An actual spectral gap has g=x+hE, H_F(x)y=0 and grad F(y)=grad F(x).
As in moonshots_13_14.txt, these identities imply F(g)=hQ(g) and Q(x)=Q(g).
If y=0 then H_F(x)x=0 by Euler homogeneity. The selected coordinates include
a common zero contact, so x!=0 when h!=0; h=0 is impossible since F(g)<0.
Thus H_F(x) must be singular for every actual point of this normalized cap.

Here F=-(c+1)[(a+1)^2+e]<0 and Q=e(d-1)-1. If Q=0 then F=hQ is
impossible. For Q!=0, h=F/Q. The full-pencil verifier gives
 det H_F(x)=-4(c+1)^2 P^2/Q^2.
On b=a the exact factor check gives P=J B with
 J=(a+1)^2(c+1)+e(c+1-a^2),
 B=a^4(c+1)+2a^3(c+1)(d+2)
   +a^2[5cd+ce+6c+e(d^2-d+1)+5d+6]
   +2a[cde+2cd+ce+2c+d^2e+2d+e+2]
   +cde+cd+ce+c+d^2e+de+d+e+1.
All summands of B are nonnegative and its constant term is 1, so B>0.
Thus singularity forces J=0. This requires
 delta=a^2-c-1>0, e=(a+1)^2(c+1)/delta, a>1.
For h<0 the standard Drury argument already gives the desired support
inequality. We now exclude all positive-height spectral lifts on J=0.
Since F<0, positive height gives Q<0; equivalently U=delta Q<0.

Set K=a+c+1 and let k be the following polynomial vector in the selected
permutation coordinates; omitted entries are zero:
 k0=-(c+1)K, k3=k12=(a+1)(c+1), k5=-K^2,
 k6=k10=-aK, k11=-delta, k13=a^2 c.
The equal-branch verifier checks H_F(g)k=H_F(E)k=0 identically. Because
k11=-delta!=0, deleting coordinate 11 gives a global 13-dimensional chart
for the quotient by this common null vector. Let C13(h) be that 13-by-13
principal determinant of H_F(g)-h H_F(E). Define
 U=a^2 c d-a^2 c+a^2 d-2a^2+2acd-2ac+2ad-2a+cd+d,
 A0(h)=a^2(a+1)^2(c+1)+hU,
 L(h)=a^2cd+a^2d+2acd+2ad+cd+d
   -h[a^2c+a^2+2acd+2ac+2ad+2a+cd+c+2d+1],
 B0(h)=L(h)-4ad(a+1)h.
The verifier checks the full pencil factors and the identities yielding
 C13(h)=2 A0(h)L(h)B0(h)/delta.
One derivation uses det(H_F(g)-hH_F(E))=4 lin*quad before imposing J=0.
Differentiate in e at J=0. Its e-derivative is not identically zero, so the pencil has generic
rank 13 with adjugate rho*k*k^T; the verifier checks k^T H_F(r22)k=2(c+1)delta^2>0. Equating
this derivative to rho times that quadratic form gives C13, since its
cofactor is rho*k11^2. This is a polynomial identity over the rational
function field and remains valid at every parameter in the stated domain.

At h0=F/Q=-a^2(a+1)^2(c+1)/U, A0=0 and
 C13'(h0)=2(a+1)^6(c+1)^3 T1 T2/(delta U),
 T1=a[(d-1)^2+a^2-1]+a^2(2d+1)+d^2,
 T2=(c+1)T1+4a^3d.
The verifier checks both factorizations. Since a>1, d,c>=0, T1,T2>0;
delta>0 and U<0, so C13'(h0) is strictly negative. The 13-by-13 quotient
matrix is singular with nonzero determinant derivative, hence has rank 12.
The full Hessian has rank 12 and a two-dimensional kernel. On that kernel,
Q has k in its radical because H_F(E)k=0; its restriction has rank one,
not zero, because C13'(h0)!=0.

The positive-height J=0 domain is path connected. Its base consists of
c>=0 and a>sqrt(c+1), with e uniquely determined as above. The base is path
connected: increase a enough, vary c, then adjust a. For each base point the
d fiber is the interval 0<=d<1+1/e, with the continuous section
d=(1+1/e)/2. Thus the full domain is path connected. The nonzero eigenvalue
of Q restricted to the Hessian kernel has constant sign there. At
(a,c,d,e)=(2,1,1,9), the exact restriction is
 [[140/8427,-70/2809],[-70/2809,105/2809]],
which has one positive eigenvalue and one zero eigenvalue. Hence Q is
positive semidefinite on the kernel throughout this domain. A real lift
would require Q(y)=Q(x)=Q(g)<0, impossible.

The unequal-weight part of the five-parameter cap remains open.
