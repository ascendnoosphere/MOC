Elementary multi-contact exclusions for missing Fourier blocks
31 October 2026

Let V be the14-dimensional real matching space on S4, decomposed as
  V=[4] + [31] + [22], with dimensions1+9+4.
For a contact set C, put W_C={f in V:f|C=0}. Let n be a linear functional
on V, and allow arbitrary signed-weight gauges annihilating V. Suppose a
weight representative of n has STRICTLY positive quadratic moment on W_C:
  sum_pi n_pi f(pi)^2 > 0 for every nonzero f in W_C.
The following obstructions are independent of those invisible gauges.

1. Missing standard block

If n annihilates [4]+[31], and some edge i->j occurs in NO contact
permutation, take f(pi)=1_{pi(i)=j}. Then f lies in W_C, f is nonzero,
and f^2=f belongs to [4]+[31]. Thus its n-moment is0, a contradiction.

Consequently a strict conditional moment with zero standard Fourier block
is possible only if the UNION of the contact permutations covers all16
singleton edges. For four contacts, this means the contacts form a
one-factorization of K_(4,4).

2. Missing22 block

There are three unordered pair partitions of four labels. For an input
partition I and output partition J, let
  e_J(pi)=1_{pi(I)=J}.
These are matching functions: if I is represented by its two-element
block and J by its block, e_J=r_(I,J)+r_(I,J-complement). As J ranges over
the three pair partitions, their sum is1.

Suppose every contact sends I to the SAME partition J. Write K,L for the
other two output partitions and set
  f=e_K-e_L.
Then f is nonzero, vanishes on all contacts, and
  f^2=e_K+e_L=1-e_J.
Both f and f^2 lie in [4]+[22]; this also follows from the ordinary
permutation representation on the three pair partitions. Hence if n
annihilates [4]+[22], its moment on f is0, contradicting strict positivity.

Thus a standard-only conormal profile is impossible whenever C lies in a
coset of a pair-partition stabilizer (a set of eight permutations).
This includes arbitrarily many contacts up to eight, not just one contact.
For two contacts the criterion covers relative transpositions, double
transpositions, and four-cycles. A relative three-cycle has no fixed pair
partition and is not covered by this argument.

3. Complete four-contact census consequences

Using the independently exact complete34-orbit census in
  build/moc_four_contact_orbits_20261031.json,
the singleton argument covers32 of34 contact orbits and28 of29 admitting
mixed nonnegative rays. The only remaining nonordinary representative is
the Klein four set [0,7,16,23].

The pair-partition square argument covers seven contact orbits, of which
six admit mixed rays. Their representatives are
  [0,1,6,7], [0,1,6,16], [0,1,6,17],
  [0,1,16,17], [0,1,16,23], [0,7,16,23].
The seventh orbit has no mixed rays. These counts classify only these
elementary missing-block exclusions; they do not prove the generic
multi-contact conormal theorem or actual matching-SOS containment.

4. Rank-one standard-only branch and missing-edge connectivity

Suppose additionally that the balanced singleton matrix of n is nonzero
and rank one, P=u v^T, with every row and column sum0. Then sum(u)=sum(v)=0.
Strict conditional positivity requires P_ij>0 on every edge i->j absent
from the union of contacts. Form the bipartite graph of these missing
edges. Along a connected component containing edges, all its u and v
entries have the same nonzero sign. If one such connected component
contains every row vertex or every column vertex, its zero-sum condition
is impossible. This is a purely real rank-one obstruction.

For two contacts, the missing-edge graph is connected and spans all
eight vertices for relative transpositions, three-cycles, and four-cycles.
For a double transposition it has two components, but the zero22 square
lemma already excludes the standard-only profile. Consequently the
rank-one standard-only branch is excluded for EVERY two-contact cycle
type. This uses no actual-source assumption.
The phrase standard-only is essential: dependence of both SL4 groups
does NOT in general force the22 profile to vanish. Therefore this does
not close the entire both-dependent double-transposition chart. The graph
argument handles the other three cycle types regardless of the22 block.

For four contacts the graph test combined with the zero22 square lemma
excludes nine of34 orbits, including eight of29 nonordinary orbits. It
does not settle the remaining standard-only rank-one multi-contact cases.
