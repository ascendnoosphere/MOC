The complete block-Gram interpolation equations on the star face
31 October 2026

This note gives exact affine coordinates for the ENTIRE star matching
Gram problem.  It does not prove positivity.  There are35 free Gram
directions in the full ten-feature problem, or23 when the six-primary
block is required to be diagonal.  The auxiliary four-corner is forced
to be invariant under two-qubit partial transpose in BOTH cases.

Use star contacts (0,1,2,14), the ten cost coordinates

                     w=(a,b,c,d,e,f,u,r,s,t),

and the exact evaluation matrix F in moc_star_contact/schur_psd.json.
The six primary feature names are A,B,C,D,E,F and the four auxiliary
names are U,R,S,T.  A real symmetric Gram has block form

                         [ D6    B6x4 ]
                     G = [             ].
                         [ B6x4^T C4  ]

The six pure evaluation rows fix diag D6=(a,b,c,d,e,f).  The three rows
with costs a+e,b+d,c+f force

                      D_AE=D_BD=D_CF=0.                    (1)

These are the only conditions imposed on D6 in the full problem.
There remain twelve primary off-diagonal variables.  All eleven other
interpolation equations are retained.

1. Diagonal-primary case

First set D6=diag(a,b,c,d,e,f).  Write b_XY for row X, column Y of
B6x4.  The eleven remaining equations uniquely determine C4 subject
to the ONE scalar constraint

 sum_(X=A..F)(b_XU-b_XR+b_XT) = t+u-r.                   (2)

There are24 B entries, so this is the full23-dimensional affine
primary-diagonal solution space.  On (2), the ten entries of C are

 C_UU=2b_EU+2b_FU-u,
 C_UR=b_EU+b_FU+b_FR+b_BU-b_BR+b_CU-u,
 C_US=-b_AU+b_ES+b_FU-b_BS,
 C_UT=-b_AU+b_FR-b_BT,

 C_RR=2b_FR+2b_CR-r,
 C_RS=C_UT,
 C_RT=-b_AR+b_CT+b_DT+b_FR+b_FT+b_AT-t,

 C_SS=s-2b_AS-2b_BS,
 C_ST=b_DS-b_AS+b_FT-b_BT,
 C_TT=2b_DT+2b_FT-t.                                     (3)

The exact checker substitutes (2)--(3) into all24 cost equations,
including all four contacts and all eleven remaining nontrivial rows.
It also checks that the23 free homogeneous Gram directions are
linearly independent.  Thus (2)--(3) describe the complete diagonal
ansatz, not a smaller empirical section.

2. General primary block

Allow all twelve primary off-diagonals not forbidden by (1).  The
same linear solve determines C uniquely from D,B subject to

 sum_(X=A..F)(b_XU-b_XR+b_XT)
       +D_AB+D_AC+D_BC-D_DE-D_DF-D_EF = t+u-r.            (4)

The explicit affine C(D,B) is exported in the artifact below.  Solving
(4) for b_AU leaves23 other B entries and12 primary variables: the
FULL35-dimensional matching Gram kernel.  All35 exported generators
are checked independent, and every one has zero cost evaluations.
The ten affine cost generators are also exported.

3. The forced partial-transpose identity

For both the general and diagonal lifts,

                              C_UT=C_RS.                  (5)

This is intrinsic.  Let Sigma=diag(sgn(pi)) on the24 evaluations.
Exact multiplication gives

              F^T Sigma F = 0_6 directsum H_(UT-RS).

Every matching cost is orthogonal to the sign character.  Therefore

 0=sum_pi sgn(pi) g_pi=tr(G F^T Sigma F)=2(C_UT-C_RS),

proving (5) without choosing a lift or using positivity.  In the tensor
ordering U=00,R=01,S=10,T=11, real symmetric two-qubit partial
transpose swaps exactly the UT and RS entries.  Thus C^Gamma=C.
In particular C PSD implies that this corner is automatically PPT.
This assertion concerns C, not partial transpose of the full G.

4. The remaining constructive problem

If D is positive definite, the exact positivity criterion is

                 G PSD iff C-B^T D^-1 B PSD.              (6)

For singular D, the corresponding criterion uses range B contained
in range D and C-B^T D^dagger B PSD.  Equations (3) or the full affine
lift turn (6) into an explicit matrix Riccati inequality with every
matching equation already satisfied.

For actual generic star costs, the independently derived source
Schur matrix S4 is PSD of rank2.  A proposed constructive identity is

                  C-B^T D^-1 B=T^T S4 T.                  (7)

This note does not establish (7), select B or T, or prove that the
diagonal-primary restriction is feasible.  It supplies the full
interpolation coordinates in which to seek such a source-dependent
identity.  In particular the source S4 should not be inserted as a
fixed pullback and assumed to reproduce costs; those earlier direct
pullbacks failed their matching identities.

The artifact contains the23-parameter and35-parameter versions, every

Prescribed-block API

 Import StarBlockLift from moc_star_block_gram_affine.
 G=StarBlockLift().complete(w,D6,B6x4,adjust_b00=True)

This preserves the prescribed D6, changes only B[A,U] to satisfy(4),
solves C4 exactly, and checks all24 evaluations.  With adjust_b00=False
the cross block must already satisfy(4).  Rational or exact algebraic
SymPy entries are supported; positivity must be checked separately.

Subsequent construction status

The actual control excludes D6=diag(a..f) by an exact positive-definite
dual certificate; see moc_star_primary_diagonal_obstruction_20261031.txt.
Thus the general lift retaining all twelve primary coherences is needed.
The simple four-state feedback substitution B=B0+UX also has an exact
zero-kernel obstruction; see moc_star_feedback_are_obstruction_20261031.txt.
Neither obstruction excludes the full35-parameter Gram problem.
