The unrestricted gap remains the same: actual support maximizers whose every

1. Existing branches that should not be re-opened

docs/research/branch_A_maximizer_geometry.md proves that a zero nonstabilizer
pair curvature at an actual maximum gives an exact full U(2) support plateau.
Its cross-stationarity identities force generalized-circle resonance of the
effective Schur eigenvalues. The scalar-effective-Schur branch is already
closed under its stated nonendpoint, nonconcyclic assumptions.

docs/research/flat_resonance_closure.md also closes the distinct-effective-
eigenvalue branch under the stated nonendpoint assumptions. Nonzero height
forces a coordinate reducing decomposition. The exceptional zero-height
coupling is normalized by a Mobius map to a Hermitian model and then admits a
second exact support-preserving transport to a reducing coordinate.

These arguments use actual maximality along an exact plateau; replacing that
hypothesis by isolated stationarity is invalid.

2. Numerical test of a proposed unfolding into strict local maxima

Fix the real Walsh mixer W/2 from moc_pair_maximum_moonshot.txt. Perturb all
four complex entries of b and solve the six real SO(4) stationarity equations
for a_2,a_3,a_4, keeping a_1=1 and eta=i. The initial spectral point is
a=(1,-1,-3i,3i), b=(-3,3,-i,i).

With perturbation sizes .001,.01,.1,.5,1 and forty seeded trials at each size,
190 of 200 roots had stationarity residual at most 1e-7. Near the original
point the full twelve-coordinate offdiagonal Hessian retained six negative
and six numerically zero modes. Three zero modes are right-phase stabilizers;
the remaining three are physical. The perturbations did not supply a strict
nonmonomial local maximum. Larger perturbations also reached repeated/scalar
spectral solutions and saddle branches.

This is numerical evidence only. An eigenvalue normalized by the largest
Hessian eigenvalue is misleading when the entire Hessian is at residual
scale; use the maximum matching-product magnitude or report absolute values.
The raw record retains gradient residuals and all eigenvalues. Near the
original point the matching maximum is approximately twice the Walsh support;
that ratio is not an exact identity for the perturbed spectra.

3. Exact stationary functional Hessian space

The numerical degeneracy is not forced by the Walsh point alone.

Use the eighteen complementary two-minor coordinates q_(I,J), with I one of
12,13,14 and J any two-subset. For a real linear functional in these q's,
the SO(4) gradient map at Walsh has rank six. Its stationary Hessians span a
seven-dimensional real vector space. Exact rational differentiation of the
two-minors gives this calculation without inverses or spectral assumptions.

For a suitable linear parametrization x0,...,x6 of that Hessian space, put

 X1=(K12+K34)/sqrt(2),  X2=(K13-K24)/sqrt(2),
 X3=(K14+K23)/sqrt(2),
 Z1=(K12-K34)/sqrt(2),  Z2=(K13+K24)/sqrt(2),
 Z3=(K14-K23)/sqrt(2).

In the order X1,X2,X3,Z1,Z2,Z3 the Hessian is exactly

 [ -2x4+2x5+x6       0                  0           0          x6       0 ]
 [       0        x0+x2                0           0           0      x0-x2]
 [       0           0           2x1+x3-2x4        x3          0       0 ]
 [       0           0                 x3       x3-2x5        0       0 ]
 [      x6           0                  0           0       -2x1+x6   0 ]
 [       0         x0-x2                0           0          0       D ],

 D=x0-2x1+x2+2x4-2x5.

Thus it splits, after permutation of this basis, into three symmetric 2x2
blocks. The script checks the factorization of its characteristic polynomial
exactly. No rank-three assertion is proved for actual stationary spectral
inputs: explaining the observed zero block determinants requires retaining
the nonlinear spectral constraints and is an unresolved algebraic question.

As a concrete check against overgeneralization, take the functional minus the
sum of the q coordinates that vanish at Walsh. It is stationary there and
has SO(4) Hessian -2I_6. Therefore stationary common-minor functionals can be
strictly concave in all six real directions. A proof that actual spectral
inputs must retain null directions must use more than this linear profile
geometry.

4. Scope and source check

The supplied exact Walsh cubic saddle and its cross-spectral family already
have complete MOC certificates. A new test at that fixed mixer cannot by
itself close the unrestricted mixer problem. The calculation above is useful
only as a diagnostic for why second-order classification needs the actual
spectral constraints.

The primary arXiv source checked in this pass was K. Rodtes, A class of normal
dilation matrices affirming the Marcus-de Oliveira conjecture,
https://arxiv.org/abs/2006.14846v1. Its abstract states a class result, not a
universal theorem. The 2026 variational publisher abstract cited in the prior
report permits nonmonomial support maximizers, including a 2x2 example. In
dimension two the determinant range is a line segment; an interior mixer can
maximize a support only when that support is constant on the segment. Such
ties do not refute the weaker needed assertion that a monomial maximizer
exists. The full 2026 paper was not read in this pass.
