# Common permutation laws and categorical follow-up

A common permutation law reproduces the complete squared-minor kernel with one probability distribution. Its quantifiers are stronger than a certificate for a specified spectral pair. The notes distinguish these obligations and prove the stated restricted families; they do not settle unrestricted MOC.

## Reading path

1. [Follow-up manuscript](latex/MOC_Categorical_Followup.tex): the LaTeX source tying this round together.
2. [Quantifier audit](proof_notes/category_metaproof_notes.txt): common laws, product inputs, and the scalar determinant obligation.
3. [Algebraic notes](proof_notes/category_algebraic_notes.txt) and [variational notes](proof_notes/category_variational_notes.txt): the complete squared-minor kernel and its positive-law problem.
4. [Phase and graph-cycle notes](proof_notes/category_phase_notes.txt): gauge quotients and ellipse certificates.
