# Exact input data

`certificates/` contains exact witnesses and structural input tables consumed by
the retained programs or needed to audit their stated theorems. They are not
execution logs. A witness may be generated by an expensive discovery process but
is retained when an independent checker needs it as input.

`layout.json` is the source map used by `code/run.py`. Each entry records an
original path, its curated destination, the original SHA-256, whether its content
was curated, whether it is runnable, and any ordered generated prerequisites.
Hashes describe original provenance, not a hash of the rewritten document.
Byte-identical legacy aliases may share one curated destination.

Regenerable PASS reports, search logs, progress snapshots, timing summaries,
figures, and solver workspaces are not stored here. Rebuild them in a disposable
workspace; request `--output build/<name>` when a saved output is useful.
