# Theorem notes and support certificates

This collection groups the mathematical results by proof mechanism. It includes proved restricted theorems, exact equivalences, necessary conditions, and proposed universal inequalities. Each note states its own hypotheses and status; an exact reformulation alone does not settle unrestricted MOC.
